# 3. Periodo de análisis

Partir de 2006 es viable para la historia de cada empresa, pero las cifras de 2006–2011 no son comparables con las posteriores. Se propone una serie principal 2012–2025.

```mermaid
timeline
    title Hitos que afectan la serie de cifras SCVS
    2006 : Inicio propuesto por el director
    2008 : Ranking SCVS más antiguo publicado
         : Res. 08.G.DSC.010 fija el cronograma NIIF
    2010 : Primer grupo pasa de NEC a NIIF
    2011 : Segundo grupo pasa a NIIF
    2012 : Resto de compañías aplica NIIF
         : Inicio de la serie comparable
    2014 : Inicia la sección en línea de estados financieros
    2022 : Cambia el formato de los balances SCVS
    2025 : Último ejercicio disponible
```
